# Student Management System

A web-based Student Management System built using **Python, Flask, SQLite, HTML, and CSS**. The application provides user authentication and complete CRUD (Create, Read, Update, Delete) functionality for managing student records.

---

## Features

- User Signup
- User Login
- Student Registration
- Search Student by ID
- Update Student Details
- Delete Student Record
- View Registered Students
- SQLite Database Integration

---

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS
- Jinja2 Templates

## Installation

1. Clone the repository

```bash
git clone https://github.com/xenonankit/flask-student-management-system.git
```

2. Open the project folder

```bash
cd flask-student-management-system
```

3. Install Flask

```bash
pip install flask
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```
http://127.0.0.1:5000/
```
